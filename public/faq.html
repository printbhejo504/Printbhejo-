Frequently Asked Questions

Do I need to install an app?

No. PrintBhejo is designed to work through a web browser.

Do I need an account to transfer a file?

The basic transfer workflow is designed to work without requiring the sender or receiver to create an account.

How does the connection start?

The receiver generates a short PIN and the sender uses that PIN to start the connection.

Can I send multiple files?

Yes, where supported by the current transfer interface, you can select multiple files for a transfer.

How long are received files kept?

Received files are temporary and are automatically removed according to the current product retention behavior.

Why might QR scanning not work on an older phone?

QR scanning depends on browser camera access and browser capabilities. If scanning is unavailable, the PIN can be entered manually.

Which browsers are supported?

Use a current version of Chrome, Edge, Safari or another modern browser. Older devices may have reduced support for camera or browser features.
